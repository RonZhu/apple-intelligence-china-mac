# 第 9 步：完全回退到原厂安全状态

> ⚠️ 截至 2026-10-12，作者**尚未实际执行**回退。以下步骤依据 Apple 官方文档、本机 `man kmutil` 与准备阶段的记录整理，执行时请逐步核对实际状态。

回退的目标是：没有第三方内核扩展、地区恢复 CH/A、SIP 完全开启、启动安全恢复成**你在第 1.6 节记录的原始值**（通常是 Full Security）。**只删除文件不算回退完成。**

## 9.1 移除开机自动恢复任务（如果装了）

```bash
cd scripts/auto-eligibility-fix && sudo bash uninstall.sh
```

## 9.2 移除内核扩展

```bash
sudo kmutil unload -b com.local.RegionSpoof     # 在 Apple 芯片上可能失败，属正常
sudo rm -rf /Library/Extensions/RegionSpoof.kext
```

说明：
- 本机 `man kmutil` 写明 `unload` **不会**把扩展从辅助内核集合（AuxKC）里移除；Apple 芯片上卸载扩展需要重启才真正生效。
- **不要**手动删除 Preboot 卷里的内核集合文件，**不要**使用会清空所有第三方扩展的"panic medic"类命令。
- 恢复 Full Security 后，系统本身就不会再加载任何第三方内核扩展，这是最可靠的一步（见 9.3）。

## 9.3 进恢复模式恢复安全设置

按第 3.2 节进入恢复模式，然后：

1. **实用工具 → 启动安全性实用工具** → 选系统磁盘 → 安全性策略 → 选回**完整安全性（Full Security）**（或你第 1.6 节记录的原始值）。
2. **实用工具 → 终端**：

```bash
csrutil enable
```

3. 重新启动。

官方参考：[启用/停用 SIP](https://developer.apple.com/documentation/security/disabling-and-enabling-system-integrity-protection) · [更改启动磁盘安全设置](https://support.apple.com/guide/mac-help/change-security-settings-startup-disk-a-mac-mchl768f7291/mac)

## 9.4 回到系统后逐项核对

```bash
csrutil status                     # System Integrity Protection status: enabled.
csrutil authenticated-root status  # enabled
sudo bputil -d                     # 与第 1.6 节记录的原始策略一致
nvram boot-args                    # 不存在
kmutil showloaded 2>/dev/null | grep -v com.apple    # 没有 RegionSpoof
ioreg -rd1 -c IOPlatformExpertDevice | grep -E '"region-info"|"country-of-origin"'   # CH/A、CHN
```

全部与原始记录一致，才算回退完成。之后 Apple Intelligence 会恢复为不可用（国行原厂状态）。

## 9.5 网络设置（按需）

- Surge：关闭增强模式；从配置中删除 `api-siri-prod.apple.com` 的 skip-proxy 和 `PROCESS-NAME,searchtoold` 规则。
- Tailscale：恢复接管 DNS：`/Applications/Tailscale.app/Contents/MacOS/Tailscale set --accept-dns=true`。
- 语言：如需改回中文，到"语言与地区"调整。
