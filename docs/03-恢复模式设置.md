# 第 3 步：进恢复模式，降低启动安全并允许内核扩展

> 目标：让 macOS 允许加载你自己 ad-hoc 签名的内核扩展，**同时只放开必要的部分**。

## 3.1 需要改两样东西（作者第一次只改了一样，白跑了一趟）

| 设置 | 在哪里改 | 作用 |
|---|---|---|
| 启动安全策略：**降低安全性 + 允许用户管理已识别开发者的内核扩展** | 恢复模式 → 实用工具 → 启动安全性实用工具 | 允许第三方内核扩展进入系统 |
| SIP：**仅豁免内核扩展签名** `csrutil enable --without kext` | 恢复模式 → 实用工具 → 终端 | 允许加载 ad-hoc 签名（没有开发者证书）的内核扩展 |

作者第一次进恢复模式只执行了 `csrutil` 命令，回到系统安装后，"隐私与安全性"里提示 *Your current security settings prevent the installation of system extensions*，只好再进一次恢复模式补开第一项。**建议一次做完，顺序如下：先改启动安全策略，再执行 csrutil**（修改启动安全策略可能会重置 SIP 设置，所以 csrutil 放在后面）。

## 3.2 进入恢复模式（Apple 芯片）

1. 保存所有工作，**苹果菜单 → 关机**。
2. 完全关机后，**按住电源键不放**，直到屏幕出现"正在载入启动选项"。
3. 点 **选项（Options）** → **继续**。
4. 选择你的管理员账户，输入密码。

（官方说明：[在 Mac 上使用 macOS 恢复](https://support.apple.com/en-us/102518)）

## 3.3 修改启动安全策略

1. 菜单栏 **实用工具 → 启动安全性实用工具**（Startup Security Utility）。
2. 选择你的系统磁盘（通常是 Macintosh HD），点 **安全性策略…**。
3. 选择 **降低安全性（Reduced Security）**。
4. 勾选 **允许用户管理来自被认可开发者的内核扩展**（Allow user management of kernel extensions from identified developers）。
5. **不要**勾选"允许远程管理内核扩展和自动软件更新"。
6. 点好，输入密码确认。

## 3.4 只豁免内核扩展签名

1. 菜单栏 **实用工具 → 终端**。
2. 输入：

```bash
csrutil enable --without kext
```

3. 按提示确认、输入管理员账户和密码。
4. 看到成功提示后，**苹果菜单 → 重新启动**。

### 不要做的事

- ❌ `csrutil disable`（完全关闭 SIP）：关掉的保护远超需要。上游项目也说明 `--without kext` 足够。
- ❌ `csrutil authenticated-root disable`（关闭签名系统卷）：完全不需要。
- ❌ 加任何 `boot-args`，尤其是 `amfi_get_out_of_my_way=1`：上游项目明确指出它会**弄坏 PCC 云端功能**。

## 3.5 回到系统后核对实际状态

**不要相信"应该是这样"，要读出来看。**

```bash
csrutil status
```

应看到 `System Integrity Protection status: unknown (Custom Configuration)` 之类，其中 **Kext Signing: disabled**，其他大部分项目仍为 enabled。

```bash
sudo bputil -d
```

作者回来后读到的实际状态（供对照）：

| 项 | 值 |
|---|---|
| 安全模式 | Permissive（因为 SIP 有自定义豁免，显示为 Permissive 而不是 Reduced） |
| 第三方内核扩展 | Enabled |
| SIP | Customized：仅"内核扩展签名"和"内核完整性保护"相关项被关闭，其余开启 |
| 签名系统卷（SSV） | Enabled |
| boot-args | 无 |
| 远程/MDM 管理 | 全部 Disabled |

如果读出来和预期不符（例如 SIP 完全关了、SSV 被关、多了 boot-args），先停下来排查，不要继续安装。

---

✅ 完成标准：`csrutil status` 显示 Kext Signing 已关闭、其他保护基本保持；`bputil -d` 显示允许第三方内核扩展；没有 boot-args。
