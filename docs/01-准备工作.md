# 第 1 步：准备工作

> 目标：在动任何安全设置之前，确认条件满足、留好退路、记录原始状态。这一步最无聊，但最重要。

## 1.1 确认机型和系统

- **Apple 芯片的 Mac**（M1 或更新）。Intel Mac 不支持 Apple Intelligence。
- **macOS 27**。本文在 macOS 27.0.1（26A434）上完成。系统小版本更新后内核扩展可能需要重新编译（见第 2 步）。
- 至少 **20 GB 可用空间**（Apple 官方说明模型最多约 14 GB）。

```bash
sw_vers                 # 系统版本
sysctl -n hw.model      # 机型标识，例如 Mac17,15
df -h /                 # 剩余空间
```

## 1.2 备份（必须）

降低安全等级、加载内核扩展有让系统无法正常启动的可能。动手前：

- 用 **Time Machine** 做一次完整备份，并**确认备份能打开**（不是只看到"备份完成"）。
- 或保留一台可用的旧 Mac / 原有数据来源作为退路。
- 把正在进行的工作全部保存。后面会多次重启、多次进恢复模式。

## 1.3 Apple 账户地区：不能是中国大陆

Siri AI 明确要求 Apple 账户地区**不是中国大陆**。

查看位置：**系统设置 → 顶部你的名字 → 媒体与购买项目**（具体入口随系统版本略有不同）。

> 改账户地区会影响 App Store 购买、订阅、余额等，请先了解后果。本文作者使用的本来就是非中国大陆账户。

## 1.4 语言：系统语言和 Siri 语言都设为英文

Siri AI 目前**只支持英文**，并且要求 **设备语言 = Siri 语言**。

- **系统设置 → 通用 → 语言与地区**：把 **English (US)** 拖到首位（会要求重启或注销）。
- **系统设置 → Siri**：Siri 语言选 **English (United States)**。

```bash
defaults read -g AppleLanguages     # 首项应为 "en-US"
```

> 想保留中文界面：上游项目提供了"逐 App 汉化"的方案（全局保持英文，单个 App 用中文），本文作者没有使用，未验证。**不要**把全局语言改回中文，否则新版 Siri 会直接失去资格。

## 1.5 安装 Xcode 或命令行工具

第 2 步要自己编译内核扩展：

```bash
xcode-select -p || xcode-select --install
```

本文作者使用 Xcode 27.0（含 macOS 27.0 SDK）。只装 Command Line Tools 一般也够（上游项目即如此说明）。

## 1.6 记录原始安全状态（回退时要用）

**把下面每条命令的输出完整保存到一个文本文件里。** 回退时你需要知道"原来是什么样"，不能凭印象猜。

```bash
# SIP 状态（原厂应为 enabled）
csrutil status

# 已签名系统卷（原厂应为 enabled）
csrutil authenticated-root status

# 启动安全策略（需要管理员密码；原厂通常为 Full Security）
sudo bputil -d

# 原始设备地区：国行 region-info 为十六进制 <43482f41…>（即 CH/A），country-of-origin 显示为 <"CHN">
ioreg -rd1 -c IOPlatformExpertDevice | grep -E '"region-info"|"country-of-origin"'

# 启动参数（原厂通常不存在，会报 data was not found）
nvram boot-args

# 已加载的第三方内核扩展（原厂通常为空）
kmutil showloaded 2>/dev/null | grep -v com.apple
```

作者机器的原始值：Full Security、SIP enabled、Authenticated Root enabled、无 boot-args、region-info = `CH/A`、country-of-origin = `CHN`、无第三方内核扩展。

## 1.7 记录当前资格（作为对照）

```bash
sudo plutil -extract OS_ELIGIBILITY_DOMAIN_GREYMATTER.os_eligibility_answer_t raw \
  /private/var/db/eligibilityd/eligibility.plist
sudo plutil -extract OS_ELIGIBILITY_DOMAIN_SIRI_WITH_APP_INTENTS.os_eligibility_answer_t raw \
  /private/var/db/eligibilityd/eligibility.plist
```

数字含义（作者在本机 eligibilityd 中核对）：**`2` = 不符合（NOT_ELIGIBLE），`4` = 符合（ELIGIBLE）**。国行机此时两项都是 `2`。

也可以直接运行本仓库的只读体检脚本：

```bash
bash scripts/check-status.sh
```

## 1.8 打开 Siri AI 看看现状

macOS 27 中新版 Siri 是一个独立 App：`/System/Applications/Siri AI.app`。国行机此时点"新对话"会提示：

> Siri AI is not available. Open Settings to check the status.

记住这个状态，后面用来对比。
